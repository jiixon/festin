# LLM 에이전트 시뮬레이션 Phase 4: DAU 1000 운영 시뮬레이션

## 목표

Phase 1~3이 설계 검증과 피크 시뮬레이션이었다면, Phase 4는 **실제 운영에 가까운 시뮬레이션**이다.

- GitHub Actions 스케줄로 자동 반복 실행
- 피크 시간대(점심, 오후, 저녁) 트래픽 집중 패턴 구현
- Phase 3에서 남긴 숙제 해결

- [ ] Groq `retry-after` 기반 재시도 로직 개선 — fallback 없이 LLM 판단으로만 동작

- [ ] 부스별 대기열 불균형 지표 추가
